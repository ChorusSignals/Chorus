# Contributing

## Local Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Contribution Rules

- keep cohort-list changes separate from weighting logic
- include tests when consensus math changes
- keep visuals in board or feed format, not noisy node diagrams

## Pull Request Notes

- explain which cohort behavior changed
- include a sample signal feed or ranking delta
- update docs when the operator interpretation changes
