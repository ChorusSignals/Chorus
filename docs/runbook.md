# Chorus Runbook

## What Chorus Is For

Chorus tells the operator whether Solana smart-money flow is broad and cross-cohort, or whether it is only coming from one pocket of wallets.

## Daily Operator Loop

1. Run `npm run dev`.
2. Read the consensus board for the strongest aligned token.
3. Check the signal feed to see which cohort is driving the move.
4. Escalate only the names where conviction is broad enough to matter.

## What Gets Promoted

- agreement across makers, funds, teams, and traders
- repeated alignment on direction across tracked wallets

## What Gets Demoted

- single-cohort inventory skew
- isolated wallet clusters with no cross-cohort follow-through
