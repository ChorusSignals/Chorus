# Cohort Agreement

Chorus is most useful when it can tell whether makers, funds, teams, and traders are leaning the same way or talking past each other.

## Strong agreement

- Multiple cohorts point in the same direction.
- The alignment persists long enough to survive one news cycle.
- No single cohort overwhelms the rest with pure volume.

## False agreement

- Everyone echoes the same source at the same moment.
- One cohort speaks loudly while the others stay flat.
- The apparent consensus disappears as soon as positioning data updates.

## Reading the output

Agreement should be treated as a confidence amplifier for an existing thesis, not as proof on its own.
